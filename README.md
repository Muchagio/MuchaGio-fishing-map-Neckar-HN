# MuchaGio Fishing Maps – Neckar Abschnitt 5

## Version 1.1.1 – Phase 1: GIS Audit
Build: 26.07.2026

### Änderungen
- Die Gewässerlinien werden **nicht mehr hart an den technischen Such-Bounding-Boxen abgeschnitten**. Dadurch bleibt der zusammenhängende Verlauf der gefundenen OSM-Wasserwege sichtbar.
- Horkheim zeigt weiterhin nur den **Schifffahrtskanal** (`waterway=canal`).
- Abschnittsmarker 01–04 bleiben reine Navigationsmarker und werden auf die Gewässerachse gesetzt.
- Verifizierte Bauwerksmarker werden weiterhin auf die nächstgelegene Gewässerachse ausgerichtet.
- Unsichere Bauwerke bleiben ausgeblendet; Prüfbereiche erscheinen nur bei veröffentlichter Distanzregel.
- Satellitenansicht bleibt Standard.
- Version, Cache-Busting, Build-Datum und Info-Dialog wurden auf **v1.1.1** aktualisiert.

## Datenhinweis
Die Karte ist eine digitale Orientierungshilfe. Sie ersetzt weder die Hege6-Originalunterlagen noch Beschilderungen und Bestimmungen vor Ort. Die grünen Linien stellen Gewässergeometrien innerhalb der veröffentlichten Orientierungsräume dar, jedoch keine zentimetergenau vermessenen Ufer- oder Rechtsgrenzen.
